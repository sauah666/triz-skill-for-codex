# Source Notes

This skill is a synthesis of external TRIZ material. The PDFs and books are not bundled here; only the distilled working notes are.

## Sources used for synthesis

- The Right Solution at the Right Time - useful for the ideality mindset, contradiction framing, and practical inventive problem solving.
- An Introduction to TRIZ by Stan Kaplan - useful for the beginner-friendly structure and the basic language of TRIZ.
- TRIZ: A Theory of Inventive Problem Solving (Concordia University) - useful for a compact academic overview.
- The Innovation Algorithm by Altshuller - useful for the original inventive problem-solving logic and system evolution thinking.
- Classical TRIZ - useful for the classic model set and terminology.
- TRIZ for Engineers by Karen Gadd - useful for the engineering-oriented explanation style.
- OpenSourceTRIZ.com - useful for free teaching and reference material.
- TRIZ Level 1 Training Manual (MATRIZ) - useful for practitioner-level training structure.
- TRIZ Material for Beginners - useful for simplified explanations and entry-level teaching.
- Simplified TRIZ - useful for low-friction presentation of core ideas.
- TRIZ Theory of Inventive Problem Solving - useful for cross-checking terminology and workflow.

## What this repo keeps

- contradiction-first problem solving
- Ideal Final Result thinking
- resource analysis
- separation principles
- Su-Field logic
- trimming and idealization
- system evolution trends
- a lightweight ARIZ-style sequence

## What this repo does not keep

- copied book text
- scanned PDFs
- private notes
- internal-only examples
