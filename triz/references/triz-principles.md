# TRIZ Principles Reference

Use this file when `SKILL.md` needs the full principle map without dragging the whole explanation into context.

## How to pick a principle

- If one thing gets better and another gets worse, start with Segmentation, Local Quality, Asymmetry, Dynamics, or Another Dimension.
- If the same element must be opposite things, separate by time, space, scale, condition, or state.
- If the interaction is missing, weak, or harmful, use a Su-Field view and ask whether the field should change, move, or disappear.
- If the system feels bloated, trim before adding a new part.

## The 40 inventive principles

1. Segmentation - split a monolith into parts.
2. Taking out - remove troublemakers or dead weight.
3. Local quality - let different parts do different jobs.
4. Asymmetry - vary shape or behavior where uniformity fails.
5. Merging - combine compatible functions or parts.
6. Universality - make one element do several jobs.
7. Nested doll - place one thing inside another.
8. Anti-weight - offset burden with support or balance.
9. Preliminary anti-action - prevent harm before it starts.
10. Preliminary action - do useful work ahead of time.
11. Cushion in advance - add a buffer for expected stress.
12. Equipotentiality - remove unnecessary differences in level or energy.
13. The other way round - invert order, direction, or ownership.
14. Spheroidality / curvature - use rotation, curvature, or rounded forms.
15. Dynamics - let the system adapt or reconfigure.
16. Partial or excessive action - do a little more or less, then tune.
17. Another dimension - move into a new axis, layer, or plane.
18. Mechanical vibration - use oscillation, pulses, or controlled noise.
19. Periodic action - switch from continuous to rhythmic action.
20. Continuity of useful action - keep the useful action going.
21. Skipping - bypass what does not need processing.
22. Blessing in disguise - turn harm into benefit.
23. Feedback - measure output and correct.
24. Intermediary - insert a helper element or stage.
25. Self-service - let the system do some work itself.
26. Copying - use a cheaper or safer substitute.
27. Cheap short-living objects - use temporary helpers.
28. Mechanics substitution - replace mechanics with fields, chemistry, or information.
29. Pneumatics and hydraulics - use fluid or pressure effects.
30. Flexible shells and thin films - use adaptive or deformable coverings.
31. Porous materials - use holes, channels, or permeability.
32. Color changes - use visual signaling or state markers.
33. Homogeneity - make interacting parts more alike.
34. Discarding and recovering - make the useful part temporary or reusable.
35. Parameter changes - shift temperature, strength, size, or other variables.
36. Phase transitions - use state changes to unlock behavior.
37. Thermal expansion - exploit expansion or contraction from heat.
38. Strong oxidants - use reactive chemistry when appropriate.
39. Inert atmosphere - isolate from unwanted reactions.
40. Composite materials - combine materials for a better tradeoff.
