# Master_of_Illusion

Reusable skill package for convincing volume, depth, materiality, spatial presence, and subtle optical effects in 2D / 2.5D visuals.

Start here:
1. Read [`SKILL.md`](SKILL.md).
2. Fill in [`examples/context_adapter_template.yaml`](examples/context_adapter_template.yaml).
3. Use the prompt templates in `examples/` when generating or implementing visuals.
4. Read the matching research file when you need a deeper pass on a specific domain.

Design rule:
- effects are evidence, not decoration
- light and material must agree
- motion must serve meaning
- reduced-motion and performance are part of the visual contract
