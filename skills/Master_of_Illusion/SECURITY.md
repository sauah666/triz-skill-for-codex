# Security Policy

This repository is a skill package, not an application with runtime secrets.

## What to report

Please report:
- accidental inclusion of secrets
- unsafe or misleading instructions
- content that could cause a future agent to behave in a clearly harmful way
- broken assumptions that could cause data loss or dangerous automation in downstream use

## What not to report here

- ordinary wording preferences
- style disagreements
- project-specific adaptations that belong in a Context Adapter

## How to report

Open a GitHub issue or contact the maintainer through the repository's normal discussion channel.

## Scope

The security surface here is mostly informational. The main goal is to keep the skill accurate, reusable, and free of accidental unsafe guidance.
