# FAQ

## What is this?

A universal Codex skill for building or reviewing believable depth, materiality, shadow logic, and subtle optical effects in 2D / 2.5D visuals.

## Is it tied to one project?

No. The core skill is intentionally project-agnostic. Project-specific details belong in a Context Adapter.

## Do I need 3D for this?

Not by default. The point is to get believable results with layered cues first and only escalate to heavy 3D when the task truly needs it.

## Is this only for image generation?

No. It also applies to UI, illustration, product visualization, compositing, and lightweight web implementation.

## Why is there so much about light, shadow, and material?

Because the eye reads physical presence from cue agreement. If light, shadow, and material disagree, the illusion starts to fall apart.

## Why is performance part of the skill?

Because a convincing effect that breaks accessibility or tanks mobile performance is not a good effect.

## Can I fork it?

Yes. It is MIT licensed.

## What should I do first when using it?

Fill out the Context Adapter and read the matching research notes before adding effects.

## Is bloom or glow always bad?

No. It is just often overused. Keep it only when it is physically or visually justified.

## What if I want a custom project version?

Keep the core skill universal and put project-specific details into a separate adapter or derivative package.
