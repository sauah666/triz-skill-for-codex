# FAQ

## What problem does this skill solve?

It helps when the real issue is a contradiction: improving one thing makes another thing worse. That shows up in design, architecture, product, process, and service work all the time.

## Is this project an experiment?

Yes. It is a public experiment in making TRIZ usable in a compact, worker-friendly Codex skill without losing method discipline.

## Is this only for engineers?

No. It is useful anywhere the team is stuck in a tradeoff and needs a disciplined way to find a better structure instead of just picking a compromise.

## Does it require a big model?

No. The skill is intentionally short and uses a fixed output ladder, so it should still be usable on compact worker models and smaller reasoning budgets.

## What does the MIT license allow?

Basically: use it, change it, share it, and build on it. Keep the license notice and understand that there is no warranty.

## Is it a replacement for architecture review?

No. It is a method for attacking contradictions. It still needs a real problem frame and a sane implementation choice afterward.

## What is the short ladder?

The skill always tries to show:

1. Contradiction
2. IFR
3. Resource
4. Move
5. Fast test
