# Code of Conduct

This repo is small, but the rules are simple.

## Expected behavior

- Be respectful.
- Attack the idea, not the person.
- Keep feedback concrete and useful.
- Assume people are trying to help unless proven otherwise.

## Unacceptable behavior

- harassment
- slurs
- personal attacks
- deliberate bad-faith behavior
- dragging private or sensitive details into public threads

## Enforcement

Maintainers may ignore, remove, or reject contributions that violate this code of conduct.
